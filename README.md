# 🎬 Amazon Prime Video Data Analysis Dashboard

An interactive **Amazon Prime Video Data Analysis Dashboard** developed using **Microsoft Power BI** to analyze streaming content, titles, genres, production countries, release years, IMDb ratings, and audience engagement.

---

## 🎯 Project Objectives

- Analyze Amazon Prime Video content distribution
- Compare Movies and TV Shows
- Identify popular genres
- Analyze content by release year
- Identify major production countries
- Analyze IMDb ratings
- Analyze audience engagement using IMDb votes
- Create an interactive and easy-to-use dashboard

---

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning & Transformation
- GitHub

---

## 📊 Dashboard Features

### Page 1 — Overview Dashboard

The overview dashboard provides:

- Total Titles
- Total Movies
- Total TV Shows
- Average IMDb Score
- Titles by Release Year
- Top Genres
- Top Production Countries
- IMDb Score Distribution
- Movies vs TV Shows
- Release Year and Type slicers

### Page 2 — Detailed Analysis

The detailed analysis page provides:

- Top 10 Titles by IMDb Votes
- Top 10 Titles by IMDb Score
- IMDb Votes by Title
- Average IMDb Score by Type
- Movies vs TV Shows comparison

---

## 📈 Key Insights

- Movies represent the majority of the available titles.
- The dashboard shows the distribution of content across different release years.
- Drama and comedy are among the major genres represented.
- The United States is one of the largest production countries.
- IMDb scores can be compared across Movies and TV Shows.
- Audience engagement can be analyzed using IMDb vote counts.
